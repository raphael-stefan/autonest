🚀 Primeiros Passos

1. Abra o Website

Abra o arquivo index.html no seu navegador ou use Live Server no VS Code (clique "Go Live")

2. Substitua as Imagens

  • assets/logo.jpeg - Logo da sua empresa
  • assets/hero-placeholder.png - Imagem de fundo principal
  • assets/about-placeholder.png - Imagem da seção sobre
  • assets/service-placeholder.png - Imagens dos serviços

3. Configure o Calendly

No arquivo index.html, encontre a linha com Calendly e substitua:

https://calendly.com/raphael-autonestmobile

Pela sua URL do Calendly:

https://calendly.com/seu-username

4. Atualize os Textos

  • Abra index.html
  • Atualize telefone, email e endereço no footer
  • Modifique preços dos serviços conforme necessário
  • Atualize os horários de atendimento
  • Personalize descrições dos serviços

5. Customize as Cores (Opcional)

A cor primária é #ffc107 (Ouro). Para mudar:

  • Abra styles.css
  • Use Ctrl+F (Cmd+F no Mac) para procurar #ffc107
  • Substitua pela cor desejada

💡 Dicas de Customização Avançadas

  • Ativar Efeito de Partículas: Abra script.js e procure por // createParticles();
  • Mudar Velocidade de Animações: Procure por 0.8s nos valores de animação
  • Adicionar Google Analytics: Adicione seu tracking ID no HTML
  • Adicionar WhatsApp Widget: Existem várias bibliotecas disponíveis
  • Modo Claro: Descomente addThemeToggle() no script.js
