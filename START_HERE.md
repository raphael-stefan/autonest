## 🚀 PRÓXIMOS PASSOS

### 1️⃣ CUSTOMIZAR COM SUAS INFORMAÇÕES (Muito Importante!)

**Abra `index.html` e atualize:**
- Seu telefone: `+55 (11) 9999-9999`
- Seu email: `contato@autonest.com`
- Seus horários de funcionamento
- Seus preços de serviços
- Descrições dos serviços

**Abra `SETUP.html` no navegador para ver um passo a passo visual!**

### 2️⃣ SUBSTITUA AS IMAGENS

Copie suas imagens reais para a pasta `assets/`:
- `logo.jpeg` - Seu logo
- `hero-placeholder.png` - Imagem principal (1920x1080)
- `about-placeholder.png` - Imagem da seção sobre
- `service-placeholder.png` - Imagens dos serviços

### 3️⃣ CONFIGURE O CALENDLY

1. Crie conta em calendly.com
2. Configure seus horários disponíveis
3. Pegue sua URL do Calendly
4. No `index.html`, procure por `calendly.com/raphael-autonestmobile`
5. Substitua pela sua URL

### 4️⃣ TESTE TUDO

- Abra `index.html` no navegador
- Verifique todas as animações
- Teste em mobile
- Teste o agendamento pelo Calendly
- Clique em todos os botões

### 5️⃣ FAÇA DEPLOY

**Opção 1: Netlify (Recomendado - Gratuito)**
1. Vá em netlify.com
2. Faça login com GitHub ou email
3. Arraste a pasta do projeto
4. Pronto! Site está ao vivo

**Opção 2: GitHub Pages**
1. Crie um repositório no GitHub
2. Faça upload dos arquivos
3. Ative GitHub Pages nas configurações
4. Acesse seu site via github.io
