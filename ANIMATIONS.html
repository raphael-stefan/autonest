Como Customizar as Animações

1. Alterar Duração da Animação

No arquivo styles.css, encontre a animação desejada e mude o tempo:

/* Padrão: 0.8s */
animation: fadeInUp 0.8s ease-out;

/* Mais rápido: 0.3s */
animation: fadeInUp 0.3s ease-out;

/* Mais lento: 1.5s */
animation: fadeInUp 1.5s ease-out;

2. Alterar Timing Function

Escolha entre ease-out, ease-in, ease-in-out, linear:

ease-out: Começa rápido e termina devagar
ease-in: Começa devagar e termina rápido
ease-in-out: Devagar no início e fim
linear: Velocidade constante

3. Criar Novas Animações

Adicione no CSS:

@keyframes meuaEfeit {
  0% { opacity: 0; transform: translateX(-50px); }
  50% { opacity: 0.5; }
  100% { opacity: 1; transform: translateX(0); }
}

.elemento {
  animation: minhaAnimacao 1s ease-out;
}

💡 Dicas Profissionais

  • Use animações de 0.3s a 0.8s para melhor experiência do usuário
  • Não anime mais de 2-3 elementos simultaneamente para não ficar lento
  • Use ease-out para animações de entrada
  • Use ease-in para animações de saída
  • Evite animações muito complexas em mobile
  • Teste em diferentes navegadores para compatibilidade
  • Use transform ao invés de mudar posição (melhor performance)
  • Combine animações para criar efeitos interessantes
  • Use animation-delay para criar cascatas de animações
  • Verifique o FPS com DevTools (F12) para otimizar performance

Exemplo Prático: Criar Efeito Customizado

Scenario: Animar card ao passar o mouse

HTML:

<div class="custom-card">
  <h3>Meu Card</h3>
  <p>Conteúdo aqui</p>
</div>

CSS:

@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(30px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.custom-card {
  background: rgba(255, 193, 7, 0.05);
  padding: 20px;
  border-radius: 10px;
  transition: all 0.3s ease;
  animation: slideUp 0.8s ease-out;
}

.custom-card:hover {
  background: rgba(255, 193, 7, 0.1);
  transform: translateY(-10px);
  box-shadow: 0 20px 40px rgba(255, 193, 7, 0.2);
}

🎯 Performance Tips

  • Use DevTools (F12 → Performance) para medir animações
  • Prefira CSS animations a JavaScript animations
  • Use transform e opacity para melhor performance
  • Evite animar width, height, left, top
  • Teste em dispositivos móveis reais
  • Use will-change com moderação
  • GPU acceleration com transform: translateZ(0)
  • Desative animações em @media (prefers-reduced-motion)
